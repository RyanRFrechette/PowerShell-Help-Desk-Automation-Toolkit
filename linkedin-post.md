# LinkedIn Post - PowerShell Help Desk Automation Toolkit

I finished a PowerShell Help Desk Automation Toolkit for my IT support portfolio.

This project includes 6 read-only PowerShell scripts for common first-level Windows troubleshooting:

- System information
- Disk space review
- Network connectivity checks
- Local user account summary
- Support report generation
- Recent event log errors

Each script includes saved output and screenshot proof in the GitHub README.

The goal was to show practical Windows troubleshooting, PowerShell automation, support documentation, and Git/GitHub workflow in a way a help desk or junior IT support hiring manager can review quickly.
